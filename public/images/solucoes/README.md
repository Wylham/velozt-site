# Fotos das páginas de soluções

Adicione aqui as fotos finais, com estes nomes:

- `salao-e-comandas.webp`
- `pedidos-e-producao.webp`
- `caixa-e-pagamentos.webp`
- `gestao-e-relatorios.webp`

Cada página já informa o caminho do seu arquivo enquanto a foto não estiver disponível. Ao importar as imagens, o componente pode ser atualizado para exibi-las diretamente nesse mesmo espaço visual.
